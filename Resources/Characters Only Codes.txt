Codes for rendering only the characters (the stage, its particles, the HUD and screen flashes are not drawn).
Every code here only changes what is drawn; game logic, collision and RNG are untouched, so replays stay in sync.
Use them with the Required Codes (input timing + flicker) and without any stage background code.

$Hide Stage - Characters Only [AlphaSolveVideo]
*Skips drawing every stage model on every stage: main stage, platforms, background, moving parts
*(FoD platforms, Stadium transformations and screen, Randall, FD backgrounds...). Fighter shadows go too:
*Melee projects them onto the stage. Use instead of the stage background codes (none are needed).
*Display only: Camera_80030AC4 ("is the stage visible?", the switch behind Develop Mode's X + D-pad down
*"hide stage") always answers no. Only the stage draw callback (grDisplay_801C5DB0) and the collision-debug
*overlay read it; collision, hazards, timers and RNG are untouched.

$Hide HUD and Overlays [AlphaSolveVideo]
*The HUD camera draws nothing: percents, stocks, timer, Ready/GO/GAME!, P1/CP indicators, HUD particles.
*The off-screen magnifying-glass bubbles and name tags see the HUD as hidden (ifAll_IsHUDHidden returns true).
*Display only: the HUD still runs (unlike "Optional: Hide HUD", which skips creating it); only drawing stops.
